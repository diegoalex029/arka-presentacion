ARKA — Plataforma de E-Commerce

¿Qué es ARKA?​

ARKA es una plataforma de comercio electrónico enfocada en productos tecnológicos, construida sobre una arquitectura de microservicios que resuelve de forma robusta los retos de escalabilidad, desacoplamiento y trazabilidad en un sistema de ventas en línea.

Decisiones técnicas clave​

Arquitectura Hexagonal​

Cada microservicio implementa Ports & Adapters mediante el scaffold de Clean Architecture de Bancolombia. Esto garantiza que la lógica de negocio sea completamente independiente de frameworks, bases de datos y sistemas externos.

Programación Reactiva​

Se eligió Spring WebFlux + R2DBC sobre Spring MVC + JPA por su modelo no bloqueante, que permite manejar mayor concurrencia con menos recursos — especialmente relevante en un sistema con múltiples microservicios comunicándose de forma asíncrona.

Servicios REST​

Cada microservicio expone una API REST con códigos HTTP semánticos:

  • 200 OK — operación exitosa
  • 400 Bad Request — datos inválidos o faltantes
  • 404 Not Found — recurso no encontrado
  • 422 Unprocessable Entity — regla de negocio violada

Mensajería Asíncrona​

Los microservicios se comunican mediante Apache Kafka siguiendo el patrón Saga Coreografiada — ningún servicio llama directamente a otro, sino que reacciona a eventos.

Infraestructura AWS​

Toda la infraestructura está definida como código en CloudFormation y simulada con LocalStack:
