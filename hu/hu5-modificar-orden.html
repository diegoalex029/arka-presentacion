HU5 — Modificar orden antes de confirmación

Como usuario,
quiero modificar mi pedido antes de confirmarlo,
para corregir errores o ajustar cantidades.

Criterios de aceptación​

  • Solo se pueden modificar pedidos en estado DRAFT
  • Se puede agregar un producto nuevo a la orden
  • Si el producto ya existe, se suma la cantidad
  • Se puede eliminar un producto de la orden
  • Al eliminar el último item, la orden pasa a ABANDONED
  • Al eliminar un item se libera el stock reservado

Estado actual de la implementación​

Nota importante

El sistema crea automáticamente una orden en estado DRAFT cuando se agrega el primer item. Por diseño, no es posible agregar items a una orden en un estado diferente a DRAFT — el sistema siempre busca o crea una orden draft para el cliente.

Endpoints disponibles​

Content-Type: application/json

{
  "customerId": 1,
  "productId": 2,
  "quantity": 2,
  "unitPrice": 6800000.00

Respuesta — 200 OK​

  "customerId": 1,
  "orderId": 5,
  "productId": 2,
  "quantity": 5,
  "message": "Product quantity updated in order"
}

}

Validación de estado DRAFT en el dominio​

La validación está en el núcleo del dominio — no en el handler ni en el use case:

private void validateStatus() {
    if (status != OrderStatus.DRAFT)
        throw new ResourceNotFoundException(
            "Only DRAFT orders can be modified"
        );
}

public void removeItem(ProductId productId) {
    validateStatus(); // lanza excepción si no es DRAFT
    items.removeIf(item ->
        item.getProductId().value().equals(productId.value())
    );
    this.touch(); // actualiza updatedAt
}

Suma de cantidad si el producto ya existe​

La lógica también vive en el dominio:

public void addItem(ProductId productId, Quantity quantity, Money unitPrice) {
    validateStatus();
    Optional<OrderItem> existing = items.stream()
            .filter(item -> item.getProductId().value().equals(productId.value()))
            .findFirst();

    if (existing.isPresent()) {
        // Suma la cantidad al item existente
        int newQty = existing.get().getQuantity().value() + quantity.value();
        existing.get().changeQuantity(new Quantity(newQty));
        this.touch();
        return;
    }
    // Agrega nuevo item
    items.add(new OrderItem(productId, quantity, unitPrice));
    this.touch();
}

Liberación de stock al eliminar​

Cuando se elimina un item ms-inventory recibe el evento y devuelve el stock con un movimiento tipo RELEASED:

public Mono<Void> execute(StockReleaseRequestedEvent event) {
    return productRepository.findById(event.productId())
            .flatMap(product -> {
                int previousStock = product.getStock();
                product.updateStockBy(event.quantity()); // suma de vuelta
                return productRepository.save(product)
                        .flatMap(saved -> {
                            StockMovement movement = StockMovement.createReleased(
                                    saved.getId(),
                                    previousStock,
                                    saved.getStock(),
                                    event.orderId(),
                                    LocalDateTime.now()
                            );
                            return stockMovementRepository.save(movement);
                        });
            })
            .then();
}
