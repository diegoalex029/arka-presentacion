HU3 — Reporte de bajo stock

Como administrador,
quiero obtener un reporte de productos con bajo stock,
para tomar decisiones de abastecimiento a tiempo.

Criterios de aceptación​

  • El umbral de bajo stock es configurable
  • El reporte se genera automáticamente cada cierto tiempo
  • El reporte también se puede generar manualmente
  • Se exporta en formato CSV
  • El archivo se almacena en S3

Generación manual — endpoint​

GET http://localhost:8081/api/products/low-stock-report?threshold=10

Respuesta exitosa — 200 OK​

{
  "filename": "reports/low-stock-report-2026-04-20 00_29_39.csv",
  "message": "File generated successfully"
}

Generación automática — flujo AWS​

El reporte se genera automáticamente mediante una integración entre servicios AWS:

Paso a paso​

1. EventBridge dispara una regla cada 10 minutos y envía un mensaje a SQS:

rLowStockReportRule:
  Type: AWS::Events::Rule
  Properties:
    ScheduleExpression: "rate(10 minutes)"
    State: ENABLED
    Targets:
      - Id: low-stock-target
        Arn: !GetAtt rLowStockReportQueue.Arn

2. SQS recibe el mensaje y lo mantiene hasta que ms-inventory lo consuma.

3. SQSLowStockReportConsumer en ms-inventory escucha la cola continuamente:

// Cuando llega un mensaje ejecuta el caso de uso
generateLowStockReportUseCase.generateCsv(threshold).subscribe();

4. GenerateLowStockReportUseCase consulta productos con stock menor al umbral y genera el CSV.

5. S3Adapter sube el archivo al bucket:

arka-inventory-reports/reports/low-stock-report-2026-04-20.csv

Umbral configurable​

inventory:
  stock:
    low-threshold: 10

Infraestructura como código​

Toda la infraestructura AWS está definida en CloudFormation (infra.yaml) y se despliega automáticamente al iniciar LocalStack. Esto garantiza que cualquier desarrollador tenga el mismo ambiente:

docker compose up -d  # levanta todo incluyendo LocalStack con la infra

Ejemplo de CSV generado​

id,name,stock,category,price
2,MacBook Air M3,3,LAPTOP,6800000.00
4,Samsung Galaxy S24,5,SMARTPHONE,3800000.00

Servicios AWS utilizados​
